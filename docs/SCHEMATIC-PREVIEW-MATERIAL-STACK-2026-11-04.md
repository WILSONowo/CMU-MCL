## 用户行为

- 扩展自带上游 v0.5.2 的基础材质，无自定义包时即可预览，不再强制选择本地 ZIP。
- 原理图页“预览材质”和预览中的“材质包”进入同一管理页；可多选导入、启用/禁用、上移/下移、移除副本。
- 自定义包按从上到下的优先级覆盖；新包加入自定义优先级末尾；默认基础包始终在最后。
- 缺失的纹理、模型和方块状态逐键回退到低优先级包，再回退基础包。返回预览后重载，不改动上游 GPU 渲染管线。
- 顺序与启用状态保存在组件数据根目录 resource-packs/packs.json，导入副本按 SHA-256 命名。单独更新扩展不会覆盖这些用户设置，移除副本不会删除原始 ZIP。
- 最多保存 16 个自定义包，启用文件合计最多 256 MiB；导入失败保留原状态，并回滚本轮新复制的文件。预览使用独立临时快照。

## 复用与兼容

materials.rs 的 PackLayer 和 compose_resource_packs 直接复用 LitematicaPreview v0.5.2 src-tauri/src/preview.rs。实际叠加仍由上游 litematica-preview-core / ResourcePack::overlay 处理，没有重写材质解析或网格化。

src/render 下原有 10 个上游文件保持不变（Windows Git 行尾归一化后内容与上游相同），线程调度、上传限流和直接 DX12 展示方式不变，无 PNG 传图。

API 2 的旧单包请求继续有效，0.3.48.13 可独立更新到扩展 0.2.3 并获得基础回退。首次免选文件和多包管理需要一次客户端 UI 适配（0.3.48.14），这是用户确认的完整方案。旧扩展 0.2.2 在新客户端仍走原单包入口。

基础包是上游 Assets/pack.zip 的原始字节，6,947,020 字节，SHA-256 28489e81959ca494934557b2ad5e0fdbbfdf9feaea8bc6266d5f0e915da45c02，pack_format 71。资源内嵌于 worker，同时在 Source.zip 中保留构建所需资源和来源说明。Minecraft 资源的独立版权说明完整保留，不将其宣称为 AGPL；用户自定义材质不进入分发包。

基础包覆盖范围对应上游 v0.5.2；模组方块等额外内容仍需要相应资源。PBR/特定模组渲染能力不会因多包叠加而自动增加。
