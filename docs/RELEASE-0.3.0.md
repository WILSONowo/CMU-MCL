# CMUmcl 0.3.0 Windows x64

此版汇总客户端功能；实际发布状态以仓库 Releases 和签名更新清单为准。

## 安装与使用

完整解压发行包后运行 `CMUmcl.Start.exe`。缺少 .NET Desktop Runtime 10 x64 时，引导器提示从微软下载，用户确认后安装并启动客户端。安装过程中可能请求 Windows 管理员确认。

客户端数据默认位于 `%LOCALAPPDATA%\CMUmcl`。发行包不得包含开发预览偏好、背景缓存、账号、游戏实例或 SDK。构建日志与验收截图保存在仓库外。

## 已包含的改动

- Java 自动/手动选择与游戏内存设置。
- 亮暗主题、背景设置、调整后的标题栏与整合包信息布局。
- 系统代理、直连、自定义 HTTP/SOCKS5 代理。
- 主题资源复用、图像解码优化和最小化时暂停自动换图。
- 原生依赖安装引导器，以及现有独立更新器。

## 发布检查

测试方法见 [TESTING.md](TESTING.md)，引导器构建与验收见 [RUNTIME-BOOTSTRAP.md](RUNTIME-BOOTSTRAP.md)。发布前分别验证更新协议、设置界面、干净 Windows 的依赖安装，以及受控测试账号的完整流程；不要将组件测试结果描述为实机全流程验收。

线上更新使用既有签名发布流程。签名私钥、发布凭据及部署记录保存在私有运维系统中。
