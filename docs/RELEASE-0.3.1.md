# CMUmcl 0.3.1：登录页主题统一

实际发布状态以仓库 Releases 和签名更新清单为准。

- 登录窗口采用主界面的配色、字体、小圆角、标题栏按钮和社区标识。
- 登录页可切换亮暗主题并保存；切换时保留输入内容。沿用已有背景设置，表单使用不透明面板保证可读性。
- 版本号读取当前客户端版本，不再写死为 0.1.0。
- 保留账号认证、记住登录、角色选择、注册和找回密码流程。
- 使用原生运行环境引导器；缺少 .NET Desktop Runtime 10 x64 时提示下载安装。

发布检查：执行 [设置、背景与代理测试](TESTING.md)，验证亮暗主题、自定义背景及校验提示。账号登录、游戏启动和干净 Windows 的运行库安装需单独验收。
